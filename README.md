# 陽光守門員：智慧太陽能板異常檢測系統

> 本文件為 **經濟部智慧創新大賞** 參賽所用

## 專案介紹

隨著再生能源需求提升，大型太陽能場域的維運管理也變得更加重要。傳統人工巡檢方式耗時、耗力，且在大規模場域中不易即時掌握每片太陽能板的異常狀況。

**陽光守門員**是一套智慧太陽能板異常檢測系統，整合紅外線（IR）與可見光（RGB）影像，透過影像分析技術協助使用者快速辨識太陽能板異常狀況。系統提供 Web 操作介面，使用者只需上傳影像，即可查看整體檢測結果，並進一步檢視單片太陽能板的詳細異常資訊與對應影像。

## 解決問題

大型太陽能場域常面臨以下維運挑戰：

- 人工巡檢耗時且成本高
- 場域範圍大，不易逐片檢查
- 異常狀況可能無法即時發現
- 單一影像資訊不足，影響判讀完整性
- 維運人員需要更直覺的視覺化輔助工具

本系統透過智慧影像分析與視覺化介面，協助維運人員更有效率地掌握太陽能板健康狀態。

## 系統功能

### 影像上傳

支援使用者上傳紅外線（IR）與可見光（RGB）影像，作為後續異常檢測依據。

### 異常檢測

系統自動分析影像中的太陽能板狀態，偵測可能存在異常的區域或單片太陽能板。

### 整體結果瀏覽

使用者可在 Web 介面中查看整體場域或影像的檢測結果，快速掌握異常分布情形。

### 單片太陽能板詳細資訊

使用者可點選單片太陽能板，查看該面板的異常資訊、判讀結果與對應影像。

## 技術特色

- 整合紅外線與可見光影像資訊
- 提供直覺式 Web 操作介面
- 支援單片太陽能板層級的異常資訊檢視
- 適用於大型太陽能場域智慧巡檢
- 具備實際維運應用價值

## 使用情境

1. 巡檢人員以無人機或其他設備取得太陽能場域影像
2. 將紅外線與可見光影像上傳至系統
3. 系統自動分析影像並產生檢測結果
4. 維運人員於 Web 介面查看異常分布
5. 針對疑似異常面板進行後續檢查與維修
